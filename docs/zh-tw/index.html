產品功能與玩法

四名玩家分為兩隊，對家為隊友，以兩副牌進行合作競技。產品流程包含大廳選場、匹配入座、發牌、輪流出牌、結算和升級；常見牌型有單張、對子、三張、順子、連對、鋼板與炸彈。
