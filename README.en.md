# Guandan Card Game Rules, Tournament and Server Project

Egg Throwing Arcade Game System is a commercial-oriented Guandan card game source code and operations-planning project. It covers Guandan rules, team-based card gameplay, level progression, rotating-table event design, tournament system, market research, operations plan, product design documents and C++ game server implementation direction.


## Positioning


- Guandan game source code
- Throwing Eggs card game source code
- C++ card game server and rule engine
- Rotating-table mode, tournament system, room system and operations activities
- Product planning, market research and operations documents from a multi-year operating project
- Suitable for commercial evaluation, private deployment and secondary development


## Core Features


- Guandan rules: level progression, tribute, anti-tribute, teammate cooperation, bombs, straights and combination hands
- Match system: friends rooms, points rooms, tournament rooms, private tables, team battles and hand records
- Tournament system: scheduled events, knockout matches, score events, leaderboards, rewards and registration flow
- Rotating-table gameplay: multi-table rotation, group matching, event rhythm and operations design
- Operations documents: market research, operations plan, activity design, retention strategy and monetization design
- Technical direction: C++ rule engine, room services, settlement logic, admin configuration and database structure

## Use Cases


- Guandan, card game and regional poker-like game source code evaluation
- Tournament system, friends rooms, points rooms, rotating-table mode and operations activity development
- Secondary development for C++ card game servers, rule engines and admin systems
- Product validation for Chinese card game, casual competitive and regional board-card markets
- Technical and operations reference for game studios, card-game platforms and source-code buyers


## Public Repository Scope


The public repository should show product structure, selected source examples, screenshots, market-research summaries and technical documentation. Do not publish real user data, payment secrets, admin accounts, production databases, private operations data, risk-control parameters, real orders or unlicensed assets.
